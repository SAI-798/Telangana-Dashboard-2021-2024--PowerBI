# Telangana-Dashboard-2021-2024--PowerBI
Interactive Power BI dashboard analyzing Telangana state data.

## 📌 Project Overview
This project is an interactive Power BI dashboard developed to analyze Telangana state data using various visualizations and KPIs. The dashboard helps users explore trends, compare metrics, and gain meaningful insights through an easy-to-use interface.

## 📊 Features
- Interactive dashboard
- KPI cards for quick insights
- Bar charts
- Line charts
- Pie/Donut charts
- Filters and slicers
- User-friendly navigation

## 🛠️ Tools Used
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)

## 📂 Project Files
- `TELANGANA DASHBOARD.pbix` – Power BI project file

## 📈 Dashboard Highlights
- Data visualization
- Trend analysis
- Performance indicators
- Interactive filtering
- Clean dashboard design

## 🚀 How to Use
1. Download the `.pbix` file.
2. Open it using Microsoft Power BI Desktop.
3. Refresh the data (if required).
4. Explore the dashboard using the available filters and visuals.
